# AGENTS.md

Це мій навчальний проект на Next.js. Він для лабораторних робіт з агентної інженерії, у ньому я перевіряю роботу ШІ-агентів.

## Стек

- TypeScript (strict), Next.js (App Router), Vitest.
- Node.js 24, менеджер пакетів npm.
- Перед роботою, будь ласка, перевіряй залежності в `package.json`, не вигадуй бібліотеки, яких там нема.
- Моделі та їхні налаштування знаходяться в `src/models.ts`.

## Команди

- `npm test` — запуск тестів.
- `npm run typecheck` — перевірка типів.
- `npm run lint` — перевірка коду.
- `npm run build` — перевірка збірки проєкту.
- Перед повідомленням про завершення завдання запускай необхідні перевірки, якщо перевірка не пройшла, поясни причину, а не повідомляй, що все готово.

## Межі

- Не відкривай і не змінюй `.env` та `.env.local`.
- Не змінюй `package.json` і `package-lock.json` без мого дозволу.
- Не змінюй тести, які вже є тільки для того, щоб сховати помилку.
- Не редагуй записи в `.agent-log/` вручну.
- Не видаляй файли та не виконуй `git push` без мого дозволу.
- Не використовуй платні API без мого дозволу.
- Не запускай фонові процеси без мого дозволу.

## Домовленості

- Модель обирається роллю з `src/models.ts` (`MODELS.cheap`), а не рядком-ідентифікатором.
- Ціни й дати зняття моделей звіряються зі сторінкою вендора, а не з пам'яті.
- Відповідай українською мовою, якщо я не прошу іншою.
- Нові функції додавай у відповідних папках, файлах проекту.
- Дотримуйся стилю вже написаного коду.
- Не додавай лишні бібліотеки, якщо завдання можна виконати тими, що вже є.
- Якщо щось неясно, то спочатку запитай мене.
- Повідомлення комітів пиши коротко, англійською, наприклад: `fix: correct test error`.
- Якщо змінюєш функції, перевір, чи потрібні нові тести.
- Не пиши, що команда успішно виконана, якщо ти її не запускав.
- Завдання вважається готовим після успішних перевірок і мого підтвердження.
